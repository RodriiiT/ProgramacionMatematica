## Descripción del Proyecto

Este repositorio contiene la implementación de dos módulos de optimización desarrollados bajo el paradigma de Programación Orientada a Objetos (POO). El proyecto resuelve problemas de asignación con restricciones geográficas y de recursos, utilizando técnicas de programación matemática.
